다목적 소프트웨어

일상의 문제를 해결하기 위한 유틸리티와 자동화 도구를 개발하며, 팀 협업을 통해 프로젝트 관리 역량을 강화합니다.

프로젝트 소개

소프트웨어 프로젝트 팀은 Python을 중심으로 데이터 처리, 자동화 스크립트, 간단한 데스크톱·CLI 도구를 만듭니다. 실생활과 학교 생활에서 겪는 불편을 기술로 해결하는 것을 목표로, 아이디어 선정부터 배포까지 단계별로 진행합니다.

주요 활동

  • 문제 정의 및 요구사항 정리 워크숍
  • Python 기초·라이브러리 스터디 (pandas, requests 등)
  • 팀별 MVP 개발 및 사용자 테스트
  • GitHub 이슈·PR 기반 협업 및 문서화
